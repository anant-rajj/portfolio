// FEATURED TEAM PROJECT

VeriPack — Package vs Source Integrity Analyzer

Automated software supply-chain security analyzer designed to detect unmapped backdoors, lifecycle script injections, and ghost files hidden inside published package archives.

VeriPack (pratyancha-hacktoberfest)

Hack Day Sonipat (Rishihood University × DevClub) • Problem Statement 04
42/42 TESTS PASSED • VERIFIED PRODUCTION
Role: Team Lead • Team: pratyancha (Anant Raj, Anshul Pandey, Vinayak Agrawal, Amrit Sagar)

Modern package registries (npm, PyPI) allow published tarballs to contain files and build artifacts that were never checked into public upstream Git repositories. VeriPack ingests distributed tarballs, enforces strict path-boundary sanitization to prevent Zip-Slip attacks (CVE-2018-1002204), and computes byte-for-byte provenance differentials against upstream Git trees.

Verification Engine Security Boundary Guard Deterministic Analysis Result
Archive Decompression Guard Cumulative 500 MB explosion ceiling + Path.relative_to traversal defense ZERO ZIP-SLIP EXPLOITS
Manifest Lifecycle Inspector Scans package.json & setup.py for unmapped preinstall / postinstall exfiltration hooks MANIFEST GUARD ACTIVE
AST Capability Scanner Abstract Syntax Tree traversal across dangerous primitives (child_process, fs, socket, dlopen) 0 UNAUTHORIZED ESCALATIONS
Shannon Entropy Obfuscation 8.0-bit byte-entropy frequency analysis to identify packed encrypted payloads (>5.0b threshold) ENCRYPTION DETECTED
Trojan Source Defense Unicode bidirectional control character detection (CVE-2021-42574) and zero-width spaces BIDI OVERRIDE ISOLATED
